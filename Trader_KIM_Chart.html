멀티 타임프레임 RSI 테이블

과매수=빨강 · 과매도=초록 · 일봉 RSI 27~33 → 롱 금지 · 추가 하락 가능, 67~73 → 숏 금지 · 추가 상승 가능성 높음 경고 문구 표시(완브로). 15m~월봉을 종가 기준으로 계산(60초마다 갱신, 현재가 실시간 반영).

조작법

  • 드래그 차트 상하좌우 이동 · 휠 시간축 확대/축소
  • 가격축 드래그·휠 세로 확대/축소 · A/가격축 더블클릭 자동 맞춤
  • 롱/숏 포지션 도구 클릭 한 번 → 진입·손절·익절 박스 생성, 선/박스 드래그로 조정
  • 가격축 ＋ 버튼 / 우클릭 커서 가격에 알람 만들기 · 수평선 그리기 · 주문 추가 (Alt+A · Alt+H · Shift+T)
  • 수평선 Alt+H (마우스 위치 가격에 바로 그림, 왼쪽 툴바 2번째) · 추세선 Alt+T (2번째 점 찍을 때 Shift → 수평) · 수평 레이 Alt+J · 피보나치 되돌림 Alt+F (2점) · 추세 기반 확장 Alt+E (3점)
  • 피보 롱/숏 포지션 (포지션 도구 ▸ 메뉴) ① 기준점 → ② 진입가 2번 클릭. 진입가가 1.618 레벨에 고정되도록 손절가(0)가 자동 계산되고, 목표가 = 진입가 + (진입가−손절가) × 목표 배수(기본 1). 손절가 점은 좌우로만 이동
  • 피보나치 설정 피보나치 더블클릭 또는 선택 후 ⚙ → 레벨·색·선 스타일·확장·좌표·표시 시간대
  • 가격 범위 측정 Shift+클릭 → 두 번째 클릭 (다음 클릭 시 사라짐)
  • 🔍 심볼 검색 OKX · Binance · Bitget(무기한) · Coinbase(현물) 종목 통합 검색, 거래소 탭으로 필터
  • 그림 클릭 → 선택, 점/몸통 드래그로 수정 · Delete 삭제 · Esc 취소
  • 🔔 알람 도구로 클릭 또는 Alt+A(마우스 위치 가격) → 주황 점선. 선 드래그로 가격 변경, 수평선/포지션 선택 후 🔔로 알람 전환
  • 심볼 검색 차트에서 아무 글자나 입력 · Ctrl+Z / Ctrl+Y 그림·포지션 되돌리기/다시 실행 · 하단 1D~전체 기간 버튼
  • 자석 켜면 봉의 시가·고가·저가·종가에 붙음 · Alt+R 차트 초기화
