조작법

  • 드래그 차트 상하좌우 이동 · 휠 시간축 확대/축소
  • 가격축 드래그·휠 세로 확대/축소 · A/가격축 더블클릭 자동 맞춤
  • 롱/숏 포지션 도구 클릭 한 번 → 진입·손절·익절 박스 생성, 선/박스 드래그로 조정
  • 가격축 ＋ 버튼 / 우클릭 커서 가격에 알람 만들기 · 수평선 그리기 · 주문 추가 (Alt+A · Alt+H · Shift+T) · 피보 롱/숏 포지션 계산기 (그 가격이 진입점 → 기준점만 클릭) · 시간축 ＋ 버튼 해당 시간에 수직선 (Alt+V)
  • 수평선 Alt+H (마우스 위치 가격에 바로 그림, 왼쪽 툴바 2번째) · 수직선 Alt+V (마우스 위치 시간에 바로 그림, 수평선 ▸ 메뉴) · 추세선 Alt+T (2번째 점 찍을 때 Shift → 수평) · 수평 레이 Alt+J · 피보나치 되돌림 Alt+F (2점) · 추세 기반 확장 Alt+E (3점)
  • 피보 롱/숏 포지션 (포지션 도구 ▸ 메뉴) ① 기준점 → ② 진입가 2번 클릭. 진입가가 1.618 레벨에 고정되도록 손절가(0)가 자동 계산되고, 목표가 = 진입가 + (진입가−손절가) × 목표 배수(기본 1). 손절가 점은 좌우로만 이동
  • 피보나치 설정 피보나치 더블클릭 또는 선택 후 ⚙ → 레벨·색·선 스타일·확장·좌표·표시 시간대
  • 측정 도구 (왼쪽 막대 ▸) 가격 범위 Alt+M — 가격 변화·%·틱 · 날짜 범위 Alt+N — 봉 수·기간·시작→끝·거래량 (둘 다 저장되는 그림, 드래그로 수정)
  • 빠른 측정 Shift+클릭 → 두 번째 클릭 (가격·기간 동시, 다음 클릭 시 사라짐)
  • 텍스트 Alt+X (왼쪽 툴바 3번째) — 차트를 클릭한 위치에 글자 입력 · Enter 확정 · Shift+Enter 줄바꿈 · Esc 취소 · 글자를 더블클릭하면 내용 수정 · 선택하면 위쪽 막대에서 색·크기·굵게·배경 상자 변경, 드래그로 이동 (종목별 자동 저장)
  • 🔍 심볼 검색 OKX · Binance · Bitget(무기한) · Coinbase(현물) 종목 통합 검색, 거래소 탭으로 필터
  • 그림 클릭 → 선택, 점/몸통 드래그로 수정 · Delete 삭제 · Esc 취소
  • 🔔 알람 도구로 클릭 또는 Alt+A(마우스 위치 가격) → 주황 점선. 선 드래그로 가격 변경, 수평선/포지션 선택 후 🔔로 알람 전환
  • 심볼 검색 차트에서 아무 글자나 입력 · Ctrl+Z / Ctrl+Y 그림·포지션 되돌리기/다시 실행 · 하단 1D~전체 기간 버튼
  • 📷 스냅샷 Ctrl+Shift+S / Alt+S 영역 드래그 캡처 → 클립보드 복사 (클릭만 = 전체) → 텔레그램·카톡·메모에 Ctrl+V · Ctrl+Alt+S 이미지 다운로드 · 종목별 스냅샷 보관함
  • 💾 화면 저장 Ctrl+S 이 종목의 시간 간격·차트 유형·이평선·로그·보이는 구간·RSI 테이블 저장 → 종목 전환 시 자동 적용
  • 📌 이미지 붙이기 캡처(📷·Win+Shift+S 등) 후 차트에서 Ctrl+V → 마우스 위치에 붙음 · 몸통 드래그 이동 · 우하단 점 드래그 크기 조절 · 이미지 파일 끌어다 놓기도 가능
  • 📤 백업 💾 메뉴 → 전체 백업 내보내기(.json) · 다른 브라우저/PC에서 「백업 파일 불러오기」 또는 파일을 차트에 끌어다 놓기
  • 차트 반전 Alt+I 또는 하단 「반전」 — 가격축 위아래를 뒤집어 반대 관점으로 봄 (켜져 있으면 범례에 ⇅ 반전됨 표시, 새로고침하면 해제)
  • 자석 켜면 봉의 시가·고가·저가·종가에 붙음 · Alt+R 차트 초기화
렌더링 해상도 큰 모니터에서 차트 조작이 무거우면 「자동」이나 「항상 가볍게」 · 바꾸면 화면이 새로고침됩니다
